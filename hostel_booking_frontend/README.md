# StayNest Hostel Booking — Frontend Only

A responsive static HTML/CSS/JavaScript frontend demo. It does not require Python, a database, or a backend to run.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser, or open the folder in Visual Studio Code and use the Live Server extension.

## Included
- Responsive explore/home page
- Hostel cards with images, prices, amenities and ratings
- Search by location/name, hostel type and budget
- Quick filters for verified, Wi-Fi, meals and AC
- Save/unsave stays (saved locally in browser `localStorage`)
- Hostel detail modal and demo visit-request button
- Illustrative map panel with clickable price pins
- Mobile bottom navigation

## Frontend demo limitations
Login, bookings, payments, listing submissions and live maps are placeholders. No data is sent to a server. Connect these actions to your Python/SQL backend when ready. Hostel content and prices are sample data. Google Fonts and the Unsplash images need an internet connection.
